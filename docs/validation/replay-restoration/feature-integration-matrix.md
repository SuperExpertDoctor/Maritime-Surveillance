## Update Rules

Use only these conclusions: `通过`, `已确认断链待修`, `待验证`, `按设计未触发`,
`仅扩展接口`, `仅兼容`. A positive unit test alone does not move a row to
`通过`; the row needs the causal downstream evidence required by G11.
