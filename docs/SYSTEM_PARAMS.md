> 所有参数定义与默认值。对应配置文件位于 `configs/` 目录。

## 一、任务环境

### 1.1 海域与网格

| 参数 | 值 | 说明 |
|------|:--:|------|
| 任务区域 | $300 \times 300 \text{ km}$ | 正方形海域 |
| 网格分辨率 | $30 \times 30$ | 每 cell $= 10 \times 10 \text{ km}$ |
| 大陆位置 | 左侧边缘 | `mainland_width_cells: 5` |

### 1.2 基地

| 参数 | 值 | 说明 |
|------|:--:|------|
| 基地数量 | $1 \sim 3$（可配） | 每次 reset 随机生成于大陆沿岸 |
| 基地容量 | 3 架 UAV | 单基地同时加油维护上限 |
| 基地最小间距 | 5 cells（50 km） | 随机生成约束 |
| 加油时间 | 3 min | UAV 降落→满油→起飞 |
| 障碍物安全距离 | 4 cells | 基地周围不允许生成雷云/岛屿 |

### 1.3 障碍物

| 参数 | 岛屿 | 雷云 |
|------|:--:|:--:|
| 形状 | 正方形 | 正方形 |
| 尺寸 | 1–3 cells（10–30 km） | 1–2 cells（10–20 km） |
| 数量 | 0–2 个 | 2–3 个（恒定） |
| 动态性 | 静态（初始化固定） | 动态（每步移动 $\pm 0.05$ cells/min） |
| 生命周期 | 永久 | 90–240 min 或永久 |
| 对 UAV | 可飞越 | **不可穿越**（+1 cell 安全余量） |
| 对船舶 | 需绕行 | 需绕行 |
| 对 SAR | 无影响 | 可穿透（SNR 降 $30\% \times$ intensity） |
| 对 EO/IR | 无影响 | 完全失效 |

## 二、UAV 平台

### 2.1 飞行平台（彩虹-4B 级）

| 参数 | 值 | 说明 |
|------|:--:|------|
| 数量 | 10 架 | 可配 |
| 巡航速度 | 160 km/h | 经济巡航 |
| 续航时间 | 30 h | 物理平台上限 |
| 单架次上限 | 8 h | 作战任务架次限制 |
| 最小转弯半径 | 1 cell（10 km） | Dubins 战术转弯半径 |
| 飞行高度 | 5000 m AGL（隐含） | SAR/EO 传感器基准高度 |

### 2.2 状态机

```
idle ──→ transit ──→ searching ──→ returning ──→ refueling ──→ idle
  │                     │              │
  └──── tracking ───────┘              │
         │                             │
         └── returning ────────────────┘

特殊状态:
  holding   — 基地满容，盘旋等待加油位
  refueling — 基地加油中（3 min）
```

### 2.3 燃油管理

| 阈值 | 行为 | 事件类型 |
|:--:|------|:--:|
| 25% | 燃油预警 | `uav_fuel_low_warning`（Light） |
| 8% | 强制返航 | `uav_returned`（Heavy） |
| 返航判定 | 距最近可用基地超过剩余航程的 95% | 立即返航 |

### 2.4 路径规划

| 模式 | 算法 | 传感器 |
|------|------|:--:|
| 出航（base→搜索区） | RRT\* + Dubins 避障 | 关闭 |
| 区域覆盖搜索 | Dubins 蛇形（boustrophedon） | **SAR** |
| 航路规划 | RRT\* + Dubins 避障 | 关闭 |
| 目标跟踪 | LGVF Standoff 盘旋 | **EO/IR** |
| 雷云规避跟踪 | LGVF + 斥力场（三级响应） | EO/IR |
| 返航（搜索区→base） | RRT\* + Dubins 避障 | 关闭 |
| 多机冲突消解 | 时空占用图检测 + 低优先级重规划 | — |

## 三、传感器

### 3.1 SAR 合成孔径雷达（X-band Stripmap）

| 参数 | 值 | 对标 |
|------|:--:|------|
| 条带宽度 | 15 km（1.5 cells） | STARLite / CH-4 SAR |
| 最大探测距离 | 60 km（6 cells） | 中位海况 SS3 |
| 分辨率 | 3 m | Stripmap |
| 检测概率 $P_d$ | 0.90 | 大型舰船（$>1000$ ton） |
| 虚警率 $P_{fa}$ | 0.002 | ATR 系统 + 近岸杂波修正 |
| 工作模式 | Stripmap | 侧视，近距盲区 2.5 km |
| 工作频段 | X-band（$\lambda \approx 0.03$ m） | 8–12 GHz |

**SNR 模型**：

$$\text{SNR} \propto \frac{P_t \cdot G^2 \cdot \lambda^3 \cdot \sigma_0}{z^3 \cdot v}$$

$$P_d(\text{SNR}) = \frac{1}{1 + e^{-k(\text{SNR} - \text{SNR}_{\text{th}})}}$$

**约束**：
- 每条扫描行必须直线飞行（方位向成像要求）
- 高度恒定、速度恒定、加速度零（运动补偿）
- 条带在飞行轨迹同一侧（左视/右视交替）
- 相邻条带无缝拼接

### 3.2 EO/IR 光电红外（WMD-7 / MX-15 级转塔）

| 参数 | 值 | 对标 |
|------|:--:|------|
| 视场角 | 8° | 中窄视场凝视跟踪 |
| 最大探测距离 | 20 km（2 cells） | 晴朗天气 |
| 分辨率 | 0.5 m | @ 20 km |
| 检测概率 $P_d$ | 0.92 | 锁定跟踪置信度 |
| 虚警率 $P_{fa}$ | 0.008 | 自动跟踪器（海浪反光/云雾） |
| 安装方式 | 机腹转塔 | 360° 旋转 |
| 8° FOV 地面幅宽 | 2.8 km @ 20 km | 覆盖单艘舰船足够 |

**跟踪模式约束**：
- UAV 保持在目标周围 $R_d = 1.8$ cells 盘旋
- EO 转塔持续指向目标
- 雷云遮挡 → EO 完全失效 → Level 3 紧急规避

### 3.3 舰载搜索雷达（目标舰船）

| 参数 | 值 |
|------|:--:|
| 探测距离（航母） | 4 cells（40 km） |
| 探测距离（驱逐舰） | 3 cells（30 km） |
| 方位覆盖 | 前方 ±36° 扇形扫描 |
| 检测概率 | 0.90 |
| 虚警率 | 0.005 |

## 四、舰船目标

### 4.1 目标数量与编队

| 参数 | 值 | 说明 |
|------|:--:|------|
| 目标总数 | 3–5 艘 | 随机 |
| 编队数量 | 1–3 组 | 随机，至少 1 组含 ≥2 艘 |
| 航母上限 | 1 艘 | 全场景最多 1 艘 |
| 航母编队约束 | $\geq 3$ 艘 | 1 CV + $\geq 2$ DDG |

### 4.2 舰艇类型与航速

| 类型 | 经济巡航 | 最大航速 | 说明 |
|------|:--:|:--:|------|
| **航空母舰** (CV) | 14 kn | 28–32 kn | 辽宁/山东舰级 |
| **驱逐舰** (DDG) | 20 kn | 29–32 kn | 052D/055 级 |

> 编队航速 = 编队中最慢舰艇的巡航速度。含航母的编队以航母速度（14 kn）行进。

### 4.3 机动参数

| 参数 | 值 | 说明 |
|------|:--:|------|
| Z 形规避幅度 | 3.0 km（0.3 cells） | 战术规避，网格可见 |
| Z 形规避周期 | 15 min | 完整左右摆动周期 |
| 最大航向偏差 | ±22° | zigzag 摆动角度上限 |
| 最大转弯率 | 12°/min | 大型舰艇渐进转弯 |
| 偏航时常数 | 2.5 min | 一阶滞后响应 |
| 转弯速度损失 | 12% | 满舵时航速损失比例 |
| 航向控制增益 | 0.35 | 比例控制器增益 |

**机动规则**：
- **未被跟踪**：保持基准航向，到达边界反弹
- **被 UAV 跟踪后**：启动 Z 形规避，航向按正弦曲线偏离基准方向
- **被跟踪 + 到达边界**：继续驶出，标记为 departed
- **编队 Leader**：独立导航（zigzag + 岛屿避障 + 边界检测）
- **编队 Follower**：向 `leader_pos + rotate(offset_local, leader_heading)` 站位靠拢

### 4.4 编队阵型

偏移量 $(F, R)$ 为 leader 本地坐标：$F$ = 前进方向（cells），$R$ = 右舷方向（cells）。

#### 航母编队（含 1 CV）

| 规模 | CV 位置 | DDG 分布 |
|:--:|:--:|------|
| **3 舰** | (0, 0) | (-0.8, +1.0), (+0.8, +1.0) — 两翼前出 |
| **4 舰** | (0, 0) | (-1.0, +1.2), (+1.0, +1.2), (0, -1.5) — 三面护卫 |
| **5 舰** | (0, 0) | (-1.2, +1.5), (+1.2, +1.5), (-1.0, -1.5), (+1.0, -1.5) |

```
航母编队-5 示意图（↑ = 前进方向）:
         DDG₂(+1.2, +1.5)
                    ↗
          CV(0,0)
                    ↘
         DDG₅(+1.0, -1.5)
```

#### 纯驱逐舰编队（无 CV）

| 规模 | Leader | 分布 |
|:--:|:--:|------|
| **2 舰** | (0, 0) | (+1.5, 0) — 横队 |
| **3 舰** | (0, 0) | (-1.0, +0.8), (+1.0, +0.8) — 三角 |
| **4 舰** | (0, 0) | (-1.2, +1.0), (+1.2, +1.0), (0, -1.2) |
| **5 舰** | (0, 0) | (-1.5, +1.2), (+1.5, +1.2), (-1.2, -1.2), (+1.2, -1.2) |

### 4.5 AIS 军民判别

| 参数 | 值 | 说明 |
|------|:--:|------|
| 位置偏差阈值 | 2 cells（20 km） | AIS 报告位置 vs EO 推算位置 |
| AIS 更新间隔 | 1 min | 仿真中 AIS 广播频率 |
| 判别延迟 | 2 min | 进入跟踪后积累 EO 测量样本的时间 |

**判别规则**：

| AIS 状态 | 判别结果 | 动作 |
|------|:--:|------|
| 无 AIS 信号 | **军舰**（关闭了 AIS） | 继续跟踪 |
| AIS 位置偏差 > 2 cells | **军舰**（广播虚假 AIS） | 继续跟踪 |
| AIS 位置偏差 ≤ 2 cells | **民船** | 放弃跟踪，释放 UAV |

### 4.6 目标生命周期

```
未被跟踪 ──→ UAV发现 ──→ 被跟踪（zigzag规避）
                │
        ┌───────┼────────┐
        ▼       ▼        ▼
    AIS判别   雷云丢失   驶离边界
   为民船     创建标记点  departed
        │       │        │
        ▼       ▼        ▼
    释放UAV  继续搜索   释放UAV
```

## 五、信息场

### 5.1 信息素衰减

$$I(c, r, t) = I_0 \cdot e^{-\lambda \cdot \Delta t}, \quad \lambda = \frac{\ln 2}{T_{\text{half}}}$$

| 场景 | 半衰期 $T_{\text{half}}$ | 白→灰（$I<0.7$） | 灰→黑（$I<0.2$） |
|------|:--:|:--:|:--:|
| **搜索扫描** | 30 min | $\approx 15$ min | $\approx 70$ min |
| **跟踪扫描** | 15 min | $\approx 8$ min | $\approx 35$ min |

### 5.2 信息价值

$$V(c,r) = \alpha \cdot (1 - I) + \beta \cdot S(c,r) + \gamma \cdot A(c,r)$$

| 分量 | 权重 | 含义 |
|------|:--:|------|
| 信息缺口 | $\alpha = 1.0$ | $1 - I$，越久没扫价值越高 |
| 战略价值场 | $\beta = 0.8$ | 标记点高斯扩散，$\sigma = 1.5$ cells |
| 时效性场 | $\gamma = 0.5$ | 标记点年龄衰减，$T_{\text{half}} = 45$ min |

### 5.3 态势三分法

| 态势 | 条件 | 含义 |
|------|:--:|------|
| **白态势** | $I > 0.7$ | 信息新鲜，近期刚扫描 |
| **灰态势** | $0.2 \leq I \leq 0.7$ | 信息开始陈旧 |
| **黑态势** | $I < 0.2$ | 长期未扫描，最高搜索优先级 |

### 5.4 标记点

| 参数 | 值 |
|------|:--:|
| 高斯扩散 $\sigma$ | 1.5 cells（15 km） |
| 最大年龄 | 60 min |
| 时效衰减半衰期 | 45 min |

## 七、触发事件速查

### Heavy（LLM 全管线）

| 事件 | 来源 |
|------|------|
| `target_found` | SAR/EO 发现新目标 |
| `target_lost` | 目标脱离跟踪（含雷云 Level 3） |
| `target_departed` | 目标驶离任务区域 |
| `target_military` | AIS 判定为军舰 |
| `civilian_released` | AIS 判定为民船，释放 UAV |
| `uav_returned` | UAV 油尽返航 |
| `lifecycle_completed` | UAV 全生命周期循环完成 |
| `storm_spawned` | 新雷云生成 |
| `storm_dissipated` | 雷云消散 |

### Light（仅 Hungarian 配对）

| 事件 | 来源 |
|------|------|
| `search_complete` | UAV 完成搜索区覆盖 |
| `uav_refueled` | UAV 加油完毕 |
| `base_capacity_full` | 基地满容，UAV 进入 holding |
| `uav_fuel_low_warning` | UAV 油量降至 25% |
