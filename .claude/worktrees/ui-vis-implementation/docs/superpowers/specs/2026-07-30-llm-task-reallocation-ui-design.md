# LLM 动态任务重分配系统 — Web 可视化 UI 设计文档

## 1. 设计目标

### 1.1 定位

仿真监控台 + 指挥官决策面板：实时展示 300km×300km 海域 UAV 侦察仿真的全局态势，支持直播监控与事后回放。

### 1.2 核心需求

| # | 需求 | 说明 |
|---|------|------|
| 1 | 30×30 网格地图 | 双层热力渲染（信息素明度 + 价值场色度），占主视图 70%+ |
| 2 | 实体可视化 | UAV（10 架）、船舶目标群、搜索区、跟踪区、标记点、基地 |
| 3 | 实时直播 | WebSocket 接收仿真帧，被动观察，不控制仿真节奏 |
| 4 | 离线回放 | 加载 JSONL 日志文件，播放/暂停/调速/拖拽时间轴 |
| 5 | 分层信息 | 右侧边栏常驻（UAV 列表、LLM 摘要），底部抽屉按需展开（事件、区域、LLM、参数） |
| 6 | 事件提示 | 配对连线闪 3 秒消失，触发事件有视觉标记 |

### 1.3 技术栈

- **前端**: React 18 + Vite + Canvas 2D（网格手绘渲染）
- **后端**: FastAPI + WebSocket（嵌入 Python 仿真进程）
- **日志**: JSON Lines（`.jsonl`），每行一帧完整状态快照

### 1.4 项目目录

- **可视化程序**: `vis/` 目录（React + Vite 前端 + FastAPI 后端）
- **可视化输出**: `outputs/` 目录（JSONL 日志文件等仿真产物）

### 2.1 数据流

| 模式 | 数据源 | 传输方式 | 前端控制 |
|------|--------|---------|---------|
| **直播** | Python 仿真每步通过 WebSocket 推送帧 | `{frame_id, timestamp, uavs:[...], regions:[...], info_matrix:[[...]], value_matrix:[[...]], events:[...], markers:[...], llm_cycle: {...}}` | 纯观察者，不控制仿真 |
| **回放** | 前端从 `/api/replay?file=xxx` 拉取 JSONL 文件 | HTTP GET 一次性加载全部帧到内存，前端自己驱动播放 | 播放/暂停/调速/拖拽/跳转 |

JSONL 格式：每行一个 JSON 对象，与 WebSocket 帧格式相同，仿真每步同时写入一行。

## 3. Canvas 网格地图渲染

### 3.1 坐标映射

```
网格坐标系 (col, row) → Canvas 像素坐标系 (px, py)

  cellSize  = min(canvasWidth, canvasHeight) / 32   ← 留 1 格边距
  offsetX   = (canvasWidth  - 30 × cellSize) / 2
  offsetY   = (canvasHeight - 30 × cellSize) / 2

  px = offsetX + col × cellSize
  py = offsetY + row × cellSize   (row 0 在顶部)
```

Canvas 尺寸通过 `ResizeObserver` 响应容器变化，`cellSize` 取向下取整保证整数像素。

### 3.2 渲染管线（9 层，从底到顶每帧执行）

**第 0 层 — 背景填充**
- 深色底色 `#0D1117`

**第 1 层 — 双层融合热力**

对每个 cell `(col, row)` 取 `I = info_matrix[col][row]` 和 `V = value_matrix[col][row]`，映射到 HSL：
- `H = 120 × (1 - V)`  → 0°（红，高价值）~ 120°（绿，低价值）
- `S = V × 100%` → 价值越高越鲜艳
- `L` 由信息素 I 映射：I ≥ 0.7 → 85%，I ≥ 0.2 → 60%，I > 0 → 25%，I = 0 → 10%

直觉效果：黑态高价值区 = 鲜红亮色（紧迫），白态低价值区 = 浅绿淡色（信息新鲜不需关注），白态高价值区 = 鲜绿（有目标线索的已扫描区，特殊情况很少见但正确）。

**第 2 层 — 网格线**
- 半透明细线 `#ffffff10`，1px
- 通过右上角小按钮切换显示/隐藏

**第 3 层 — 搜索区矩形**
- 半透明填充（优先级色 10% opacity）+ 2px 实线边框（优先级色）
- 优先级色：`high=#f87171`, `medium=#fbbf24`, `low=#60a5fa`
- 左上角标签：区域 id + 完成百分比（如 `S1 62%`），白色文字 + 深色背景条
- 完成态叠加 ✓ 图标
- hover 时边框加粗至 3px + tooltip 显示详情（价值、面积、分配 UAV）

**第 4 层 — 跟踪区矩形**
- 红色虚线边框 `#ef4444`, 2px, dash 模式
- 填充 `#ef444410`（极淡）
- 左上角标签 `T1` / `T2`，红色底色

**第 5 层 — 标记点**
- 脉冲圆点：半径 `r = 6 + 4 × sin(frameCount / 50)`
- 颜色按年龄：新标记（< 15min）= `#f97316` 亮橙，中年（15~45min）= `#fbbf24` 黄，老年（45~60min）= `#9a3412` 灰橙，> 60min = 不渲染
- hover 显示 tooltip：`标记 #B · UAV-3 上报 · 23min前`

**第 6 层 — 船舶 + 轨迹尾迹**
- 船舶图标：实心小三角 △，按目标群颜色区分（T1=红, T2=蓝, T3=黄）
- 尾迹：最近 10 步（10 分钟）位置的渐变线段，透明度从前到后线性衰减
- 被跟踪时外圈加脉冲光环（同目标群颜色，2px 环）

**第 7 层 — UAV 图标 + 油量 + 基地**
- UAV：小三角（指向运动方向或朝上）+ 状态色外圈
- 状态色：搜索=绿 `#22c55e`，跟踪=红 `#ef4444`，返航=橙 `#f97316`，加油=蓝 `#3b82f6`，待命=灰 `#9ca3af`
- 剩余里程环形指示：围绕 UAV 图标外侧的小弧线，弧长 ∝ 剩余里程 / 4,800km（满续航）
- id 标签：`U-3`，白色小字
- 选中 UAV 时图标放大 + 详情浮窗（点击侧边栏卡片或点击地图 UAV 图标触发）
- 基地：房屋图标 ▲，固定在 `environment.yaml` 中 base_position 位置（默认 15,28），灰色 `#6b7280`

**第 8 层 — 配对连线（瞬时动画）**
- Hungarian 配对完成时，UAV → 区域中心的动画虚线
- 亮色起点（`#60a5fa`），3 秒内渐隐至完全透明后移除
- 使用 `requestAnimationFrame` 驱动透明度插值

**第 9 层 — Hover 交互层**
- 鼠标所在 cell 高亮：2px 白色半透明边框 `#ffffff40`
- 浮窗 tooltip：`Cell(18,14) · 信息素0.23 · 价值0.82 · 黑态势`
- 区域矩形 hover：边框加粗 + 区域信息 tooltip
- UAV hover：指针样式 + UAV 信息 tooltip

### 3.3 性能策略

- `requestAnimationFrame` 驱动渲染循环，仅当接收到新帧数据时才重绘
- 直播模式：WebSocket 每步推送触发一次重绘（~1fps 仿真速率）
- 回放模式：按实际播放速率，最高 10x 速度时约 10fps，Canvas 2D 足够
- 不做脏矩形优化（30×30 grid 全量重绘在 Canvas 2D 上性能绰绰有余）

## 4. 右侧边栏

固定宽度 300px，右侧常驻，不随地图缩放。从上到下三个区块。

### 4.1 仿真状态头

```
⏱ 仿真时间          04:32:00  (大字号 HH:MM:SS)
                    第 272 步 / 480  (灰色小字)

● 直播中            绿点 + "直播中" / 蓝点 + "回放"

📡 LLM 周期
   上次: 04:30      最近一次重量触发时间
   下次: 05:00      预计下次触发时间
   状态: ✅ 通过    通过 / ❌ 失败(重试1/2) / ⏳ 待触发
```

### 4.2 UAV 状态列表

可滚动列表，每架 UAV 一张小卡片：

```
UAV 编队  8/10       ← 标题：可用数 / 总数

● U-1  搜索中  92%
  S3 区域 · 3,120km   ← 副标题按状态变化

● U-2  跟踪中  78%
  目标群#1 · 2,650km

○ U-3  返航中  31%
  返回基地 · 1,054km

◇ U-4  加油中   —
  基地 · 剩余 8min

○ U-5  待命中  100%
  基地
```

卡片元素：
- **状态图标**：实心圆=执行任务 / 空心圆=飞行中 / 菱形=地面
- **状态色**：搜索=绿、跟踪=红、返航=橙、加油=蓝、待命=灰
- **油量条**：细进度条（基于剩余里程百分比）
- **剩余里程**：数值为 km（而非百分比），满续航 4,800km
- **副标题**：当前区域 ID / 目标群编号 / 返回基地 / 加油倒计时（按状态动态切换）
- **点击行为**：地图上该 UAV 高亮居中 + 详情浮窗

### 4.3 LLM 最近决策摘要

```

  搜索区: S1 S2 S3 S4

  [查看详情]  → 点击展开底部 LLM 日志 Tab
```

## 6. 播放控制栏（回放模式）

回放模式下底部固定显示，高 48px，始终可见。

```
⏮      ⏪      ▶/⏸      ⏩      ⏭       [1x ▼]    02:15:30 / 08:00
跳到    后退    播放/    快进    跳到      速度        滑块 ─────────────
开头    10s     暂停     10s     末尾      选择
```

### 6.1 控件行为

| 控件 | 行为 |
|------|------|
| ⏮ 跳到开头 | 跳转到第 0 帧 |
| ⏪ 后退 10 秒 | 仿真时间后退 10 步 |
| ▶/⏸ 播放/暂停 | 切换播放状态，默认播放 |
| ⏩ 快进 10 秒 | 仿真时间前进 10 步 |
| ⏭ 跳到末尾 | 跳到最新帧 |
| 速度选择器 | 1x / 2x / 5x / 10x 下拉选择 |
| 时间显示 | 左侧 `HH:MM:SS` 当前时间，右侧 `HH:MM` 总时长 |
| 滑块 | 可拖拽跳转到任意时间点 |

### 6.2 键盘快捷键

仅回放模式下生效，不与浏览器原生行为冲突：

| 按键 | 行为 |
|------|------|
| `Space` | 播放/暂停 |
| `←` | 后退 1 步（1 分钟） |
| `→` | 前进 1 步（1 分钟） |
| `0` – `9` | 跳转到 0% ~ 90% 时间位置 |

### 7.2 后端 API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/ws/live` | WebSocket | 实时推送帧（每仿真步一发） |
| `/api/replay/list` | GET | 列出可用的 `.jsonl` 回放文件 |

## 8. 技术决策汇总

| # | 决策 | 选择 |
|---|------|------|
| 1 | 前端框架 | React 18 + Vite |
| 2 | 网格渲染 | HTML5 Canvas 2D 手绘 |
| 3 | 热力方案 | 双层融合：亮度=信息素，色度=价值场 |
| 4 | 布局 | 主视图 70% + 右侧边栏 300px + 底部抽屉 35% |
| 5 | 数据模式 | WebSocket 直播 + JSONL 回放 |
| 6 | 直播控制 | 纯观察者，不控制仿真节奏 |
| 7 | 回放控制 | 播放/暂停/调速/拖拽/跳转 |
| 8 | 配对连线 | 瞬态动画，3 秒渐隐消失 |
| 9 | 油量显示 | 剩余里程 km（满续航 4,800km） |
| 10 | 实体渲染 | 9 层 Canvas 管线，从底到顶固定顺序 |
| 11 | 信息面板 | 侧边栏常驻 + 底部 Tab 抽屉按需展开 |
| 12 | 参数配置 | 只读展示，来自 `/api/config` |
| 13 | 性能目标 | 直播 1fps / 回放最高 10fps，Canvas 足够 |
| 14 | 可视化代码位置 | `vis/` 目录 |
| 15 | 可视化输出位置 | `outputs/` 目录（JSONL 日志等） |
